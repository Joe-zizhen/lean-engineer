# 交付与证据

## 检查对象

列出生产构建、资源路径、环境配置、发布版本、错误监控、source map、旧动态资源和回滚路径。区分开发服务器、预览构建和生产产物。

## 必须成立的不变量

- 生产构建包含所需检查和配置。开发页面可打开不能证明生产构建正确。
- 深层路由刷新、资源 base、懒加载和旧动态 chunk 在发布窗口内可用。
- 渲染错误、事件错误和异步错误具有明确的恢复与监控路径。
- 回滚前端不等于回滚数据库、接口、交易或后台任务。

## 必造反例

- 在生产产物中直接访问深链接、刷新旧标签页和切换版本。
- 注入渲染、事件、异步、资源加载和初始化故障。
- 旧客户端访问新接口，新客户端读取旧配置。
- 监控不可用、source map 不匹配或错误发生在监控初始化之前。

## 最小证据与复验

- 在生产等价的真实托管环境检查产物，不以开发服务器代替。记录构建 ID、资源清单、路由回退、缓存策略和监控版本。
- 按风险选择构建、入口、客户端版本和故障组合。分别记录发现覆盖、页面与组件覆盖、场景覆盖、验证状态和未查原因。
- 验证深链接刷新、资源 base、懒加载、旧 HTML 与新资源、新 HTML 与旧资源、缓存和版本混用。核对 source map 与当前产物是否匹配。
- 注入渲染、事件、异步、chunk 加载和监控初始化故障。复验核心旅程、故障恢复和回滚结果。截图不能验证异步行为，本地构建不能证明生产环境已经验证。无法访问目标托管环境时保留 `blocked`。

## 来源

- [MDN HTTP Caching](https://developer.mozilla.org/en-US/docs/Web/HTTP/Caching)
- 按实际版本读取项目框架和托管平台的官方部署文档。配置只能作为 `specification`，不能作为运行证据。
