# 可访问性与布局

## 检查对象

检查 DOM 语义、可访问名称、角色、键盘路径、焦点、动态播报、触控目标、断点、缩放、主题和内容压力。

## 必须成立的不变量

- 控件可识别、可操作、可理解结果，并可退出或恢复。
- 键盘顺序符合视觉与任务顺序。弹窗打开、关闭和错误后，焦点落到明确位置。
- 状态变化以辅助技术能够理解的方式表达，不只依赖颜色或动画。
- 文本放大、长文案、翻译扩展、空数据和极值不会遮挡核心操作。
- 减少动态效果偏好不会破坏任务流程。

## 必造反例

- 只用键盘完成核心任务，并检查焦点陷阱和焦点丢失。
- 按适用标准分别检查 200% 文本缩放和重排（横向书写内容通常对应 320 CSS px 宽度，例如 1280 CSS px 视口下 400% 缩放），再检查长用户名、大数字和空内容。两类检查不互相替代；确需二维布局的对象按标准例外单独记录。
- 图标无名称、表单缺标签、错误只显示颜色、弹窗关闭后焦点消失。
- 自动播报过于频繁，动画阻断阅读或操作。

## 最小证据与复验

- 检查实际 DOM 和可访问性树。记录控件的名称、角色、值、状态和焦点路径。
- 只用键盘完成核心旅程。完整审查或关键流程使用项目支持的辅助技术复验。未执行辅助技术检查时，将对应范围记为 `not_run` 或 `blocked`，不得写成通过。
- 按风险选择组件、输入方式、缩放、窄屏和内容压力组合。覆盖上述文本缩放与重排检查，以及减少动态效果、长文案和极值。记录组合总数、已查数和未查原因。
- 自动扫描只能发现部分规则，不能证明整体可访问性。截图不能证明辅助技术行为。布局问题给出视口、缩放、内容、截图和具体位置，不把个人视觉偏好写成缺陷。

## 复杂场景的检查方法

仅在本次改动触及对应场景，或用户要求该范围完整审查时执行。先沿用项目的标准版本、目标等级、组件规范及浏览器与辅助技术支持组合；没有时说明本次检查范围，不自行宣称全面合规。新需求中的关键支持范围不明时先澄清，不阻止已有明确范围的检查。

| 场景 | 实际操作与通过条件 |
| --- | --- |
| 模态弹窗 | 用键盘打开；确认名称、初始焦点、Tab 与 Shift+Tab 在弹窗内循环，背景不可交互；验证 Escape 或约定的键盘关闭入口，关闭后回到触发点或合理后继。可关闭的模态焦点约束不是“无法退出的焦点陷阱”。优先复用原生或已有可靠组件；`aria-modal` 只声明语义，不会实现焦点与背景隔离。 |
| 日期选择器、组合框、树、可编辑表格 | 按实际组件找到 APG 对应模式，逐项走方向键、进入、选择、退出；核对焦点与选中状态及读屏反馈。静态表格不因视觉像网格就改成 `grid`。ARIA 角色不能替代键盘实现；虚拟化后仍须保留当前活动项的有效引用。 |
| 搜索结果、提交状态、异步错误 | 不移动焦点也能获知必要结果；一般更新按语义使用 `status` 或 polite，确需立即打断的消息才用 alert 或 assertive。验证首次、重复、快速连续更新的实际播报，避免逐次输入都播报整张表；不能仅凭存在 `aria-live` 判通过。 |
| 拖拽排序、移动对象 | 分别完成键盘操作和“单指针无需拖动”的替代操作，例如可聚焦的上移、下移按钮；核对结果、焦点及播报。WCAG 2.5.7 的指针要求不由键盘可用自动满足；确属标准例外时写明依据。 |
| 富文本、数据看板、复杂表单 | 用支持的辅助技术完成核心任务；核对工具栏名称与状态、错误与字段关联、图表等价信息及虚拟内容可达性。输入或提交失败后应保留用户内容和可继续操作的位置。 |

使用项目实际支持的浏览器、OS 与辅助技术组合并记录版本，例如 NVDA 配浏览器、VoiceOver 配 Safari、TalkBack 配 Android 浏览器。无需为每次小改穷举所有产品；一种组合的结果不能证明所有组合。中文与多语言界面按产品支持范围检查 `lang`、语言切换、字号和文本扩展，不自行添加未要求的语言或合规义务。

## 验收与条款对应

每个命中场景记录“要求来源 → 操作 → 预期 → 实测 → 状态”。常见映射如下，只用于定位，不是完整合规清单：

| 检查 | WCAG 2.2 对应条款 |
| --- | --- |
| 键盘可用、可退出、焦点顺序与可见性 | 2.1.1、2.1.2、2.4.3、2.4.7、2.4.11 |
| 名称、角色、状态与动态结果 | 4.1.2、4.1.3 |
| 错误识别与输入标签 | 3.3.1、3.3.2 |
| 文本缩放、内容重排 | 1.4.4、1.4.10 |
| 拖拽替代、指针目标大小 | 2.5.7、2.5.8 |

按项目目标核对适用条款的完整条件和例外。APG 用于指导交互模式，不是合规认证；未执行的组合按现有证据规则保留缺口。
