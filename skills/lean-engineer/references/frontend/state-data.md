# 状态与数据

## 检查对象

列出服务器事实、URL 状态、用户草稿、临时 UI 状态、派生状态、缓存、后台任务和流式数据。标明每份状态的拥有者、寿命、更新触发和失效条件。

## 必须成立的不变量

- 页面展示的数据属于当前实体、当前租户和当前版本。
- 较早响应不能覆盖较新的用户意图。
- 表单提交只确认对应提交快照。后续编辑不会被旧响应误清除。
- 空、加载、失败、超时未知、无权限和过期状态不会误写成成功。
- 缓存键包含实际决定数据身份和权限范围的维度。
- 断线、取消、重连和重放不会造成重复写入或错误终态。

## 必造反例

- 搜索 A 后搜索 B，但 A 更晚返回。
- 异步默认值在用户编辑后到达。
- 连续提交、提交中继续编辑、后台刷新与乐观更新并存。
- 切换账号、租户或实体时，旧请求和旧缓存仍然存在。
- 流式内容跨块、重复、重放、中断和完成与取消同时发生。

## 最小证据与复验

- 按核心旅程建立实体、租户、网络条件和请求顺序的风险选择矩阵。记录覆盖分母和未查组合。
- 使用可控延迟、乱序响应、断网、取消和重放驱动真实入口。记录请求序号、实体、租户、提交快照、服务器结果和最终 UI。
- 复验旧响应晚于新意图、异步默认值在用户编辑后到达、重复提交、账号切换和流式中断恢复。检查草稿保留、缓存失效和最终状态。
- `AbortController` 只能取消客户端等待。它不能证明服务端已经停止或撤销操作。缺少服务端证据时，将对应检查记为 `blocked`，不得推断服务端结果。
