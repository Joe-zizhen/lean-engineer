# 安全与资源

## 检查对象

列出所有信任边界、不可信输入、秘密类型、文件、下游服务、付费操作和资源消耗。不得读取真实 `.env`、私钥或凭据内容。只检查变量名、脱敏模板、受控扫描结果和秘密管理配置。

## 必须成立的不变量

- SQL、命令、路径、模板和其他解释器输入使用安全绑定或明确的上下文处理。
- 服务端获取 URL 时，协议、目标、重定向和网络边界符合明确策略。下游响应仍是不可信数据。
- 文件类型、大小、名称、存储位置、执行能力和下载授权在可信层验证。
- 不使用自定义密码学。密码、令牌和密钥使用受维护的标准机制，并具有轮换与失效路径。
- 秘密不进入源码、日志、报告、错误响应或客户端产物。已暴露秘密需要轮换，不只是删除字符串。
- 个人信息按最小必要原则收集、传输、记录、保留和删除。
- CPU、内存、存储、连接、线程、请求频率和付费调用具有与业务匹配的限制。
- Webhook 和回调验证来源、签名、重放和业务状态。

## 必造反例

在隔离环境使用无害样本：

- 参数污染、额外字段、恶意查询结构、命令分隔符和路径穿越。
- 内网地址、重定向到受限目标、异常协议和超大下游响应。
- 超大文件、伪造类型、主动内容和越权下载。
- 重放 Webhook、重复验证码请求、资源耗尽和付费流程滥用。

不得对外部或生产目标执行探测、外传或拒绝服务验证。

## 证据与复验

使用项目已有安全测试、脱敏扫描和隔离集成测试。工具告警必须结合版本、可达路径和实际防护判断。存在旧依赖或危险函数不等于已经可利用。

复验攻击路径被阻断，合法业务仍可用。不得宣称系统已经安全。通用 Review 不替代专业渗透测试。
