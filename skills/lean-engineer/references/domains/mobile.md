# 移动端检查

适用于 Android、iOS 和跨平台 App。默认只检查本次改动涉及的原生界面、生命周期、平台能力和端侧数据；纯 Web 内容使用对应 Web 专题，混合应用同时检查原生与 Web 边界。通用风险与状态分别按 [风险分档](../risk-gates.md) 和 [验证与证据](../verification.md) 执行。

## 先确定边界

按本次受影响功能记录支持的 OS/API 范围、机型类别、构建变体、应用与服务端版本，以及受影响的界面、权限、存储和后台任务。按实际部署确定旧客户端的兼容窗口和可用恢复方式；不能假设用户立即更新、后端回滚就能恢复端侧数据，或所有已安装版本都可远程修改。

## 命中后执行

| 触及内容 | 检查与反例 | 通过条件 |
| --- | --- | --- |
| 页面状态与异步任务 | 走前后台切换、导航离开与返回、系统回收进程后重建；Android 再检查适用的配置变化。区分系统回收、用户强制停止和卸载，不把重建 Activity 的测试冒充进程死亡测试 | 需保留的草稿或业务状态按要求恢复；页面销毁后没有旧回调覆盖新页面；任务不重复产生副作用。不依赖退出回调必然执行来保存关键数据 |
| 系统权限、敏感能力 | 检查首次请求、拒绝、受限授权、撤销及设置中重新授权；按 OS 版本与 API 复核后台限制。服务端权限仍需独立验证 | 权限未获授时保持约定的可用行为，不崩溃、不越权、不循环弹窗；再次进入时按当前授权状态运行 |
| 本地存储与升级 | 使用受支持旧版本生成的数据执行升级；检查 schema、加密或密钥变化、中断写入、磁盘不足、账户切换和注销。仅有缓存时按缓存语义验收 | 用户持久数据满足迁移与恢复要求，账户间不串数据；不能用清空存储掩盖迁移失败。支持降级才测降级，不擅自承诺平台可降级 |
| 网络、重试和同步 | 制造断网、恢复、超时后重试、重复提交、旧请求迟到、旧客户端访问新服务端 | 重复请求和冲突按契约处理；没有重复扣款或静默丢失编辑；状态提示与实际持久化一致 |
| 深链接、通知、WebView 桥接 | 从冷启动、后台和未登录状态进入；验证目标、参数、来源与权限，重复投递时复验副作用 | 入口验证与普通入口一致，登录跳转后不绕过授权；桥接不把任意网页变成受信任调用方 |
| 原生可访问性与布局 | 检查平台可访问性树、名称/状态/操作、焦点、大字体和内容压力；核心流程使用项目支持的 VoiceOver 或 TalkBack 等辅助技术走通 | 关键任务可识别、可完成、可退出；大字体不遮挡操作。截图或 Web DOM 检查不能代替原生辅助技术操作 |
| 启动、卡顿、内存、电量或后台工作 | 使用目标设备与接近发布配置的构建，记录工作负载、前后台状态、温度与测量方法；按症状采集 trace、内存或能耗数据 | 满足项目预算并复验功能。模拟器结果、一次不崩溃或 CPU 耗时下降不能单独证明真机稳定性或省电 |
| 发布、权限声明或平台行为变更 | 核对当前官方平台要求、应用标识、签名、构建配置和实际声明；验证受影响的新装与升级路径及分批发布/停发/前向修复方案 | 发布产物与已验证基线对应，必要声明与真实行为一致；需要平台审核或线上观察的部分仍单列，不把本地通过写成已获审核 |

## 最小证据与限制

每个命中行记录具体用例、预期来源、设备/OS、应用构建和结果。优先复用已有自动化；生命周期、传感器、后台限制及性能等依赖真实平台的结论，需要相应真机或平台证据。没有设备时保留可执行的单测和模拟器结果，将缺失的必需真机项记为 `blocked`，不否定已完成证据，也不外推到未验证环境。

发布后崩溃率、卡顿率和能耗趋势只在任务包含线上观察且有真实数据时使用；发布前无需伪造这些数值。风险接受和发布决定沿用项目授权。
