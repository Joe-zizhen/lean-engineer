# 身份与访问控制

## 检查对象

列出主体、认证方式、角色、动作、对象、字段和租户。覆盖详情、列表、搜索、批量、导出、后台任务、服务账号和静态附件。

## 必须成立的不变量

- 身份和租户来自可信执行上下文。客户端提交的 `user_id`、`tenant_id` 或 `role` 不能自行获得信任。
- 每个数据访问都执行功能级、对象级和必要的字段级授权。默认拒绝未明确允许的路径。
- 所有查询保持租户边界。缓存键、搜索索引、日志、消息和后台任务保持相同边界。
- 角色、所有者、租户和付费状态不能被批量赋值或普通请求字段提升。
- 会话过期、退出、撤销、切换账号和权限降低会终止相应访问。
- 服务账号、数据库行级安全和内部绕过路径遵循同一授权意图。

## 必造反例

使用匿名、所有者、同租户非所有者、跨租户用户、管理员和被撤销身份。对每个身份验证允许路径和拒绝路径。

- 修改路径参数、请求体、查询条件和导出参数中的对象 ID。
- 修改归属字段、角色字段、租户字段和付费字段。
- 在会话过期或权限降低后重放请求和后台任务。
- 直接访问列表、搜索、批量和导出，不只检查详情页。

## 证据与复验

优先使用服务端集成测试和真实数据库策略。前端隐藏按钮、路由守卫和 TypeScript 类型不能证明服务端授权。

拒绝路径必须证明没有受限数据、字段或写入。允许路径必须证明合法工作仍然可用。缺少服务端或数据库证据时标记 `blocked`，不得断言越权或安全。
